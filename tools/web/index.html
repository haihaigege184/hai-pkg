PG 的 tokenm.json 里 open_api_url 指向「网盘换 token 的接口」， 端扫码/刷新得到的凭据会 POST 到那里 —— 直连第三方，中枢看不见（这正是扫码后监视台无反应的原因）。
改写开启后该地址指向 /gw/ali/token：原样透传上游（端的功能不受影响）， 同时把凭据截留入库 → 其余设备下一轮拉配置即自动生效。
